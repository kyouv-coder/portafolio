## ¿Por qué GitHub para mi portafolio?

- **Control de versiones con Git:** cada cambio queda registrado y se puede revisar o revertir.
- **Alojamiento gratuito con GitHub Pages:** permite publicar sitios estáticos con una URL pública.
- **Visibilidad ante reclutadores:** el perfil y los repositorios funcionan como carta de presentación.
- **Estándar de la industria:** forks, pull requests e issues son el flujo de trabajo real de los equipos.

## Buenas prácticas que aplico

1. Definir el público objetivo: reclutadores y equipos técnicos.
2. Estructura clara: perfil, proyectos y contacto fáciles de encontrar.
3. Cada proyecto con su propio README: qué hace, cómo ejecutarlo, tecnologías y capturas.
4. Uso ordenado de Git: commits con mensajes descriptivos y `.gitignore` para no subir entornos virtuales ni datos locales.
5. Nunca publicar contraseñas, claves ni datos personales sensibles: las claves van en variables de entorno.
6. Diseño responsivo y consistente con Bootstrap.
7. Pruebas automatizadas básicas en los proyectos.
8. Contenido actualizado, con ortografía revisada.
